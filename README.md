# 초록일기 🌱

픽셀 게임 분위기로 식물의 성장과 일상을 기록하는 작은 웹 앱입니다.

## 기능

- 식물 종류, 별명, 심은 날짜 등록
- 식물별 심은 날짜 기준 D+일수 표시
- 등록한 식물이 하나면 기록 대상 자동 선택
- 사진, 한마디, 눈으로 관찰한 변화 기록
- 새싹·새잎·꽃·열매·잎 상태에 따른 관리 팁
- 서울 날씨와 물주기·환기 참고 팁
- 일기 및 달력 보기

## 실행

별도의 패키지 설치 없이 정적 웹 서버로 실행합니다. 예를 들어 VS Code의 Live Server에서 `index.html`을 열 수 있습니다. HTTPS 정적 호스팅으로 배포하는 것도 가능합니다.

## 검사

Node.js가 설치된 환경에서 실행합니다.

```sh
node --check app.js
node check-app.cjs
```

## 데이터와 날씨

사진과 기록은 브라우저의 `localStorage`에 저장됩니다. 기기나 브라우저를 바꾸면 자동으로 동기화되지 않으며, 사이트 데이터를 삭제하면 기록도 사라집니다. GitHub에는 앱 소스만 올라가고 사용자의 브라우저 기록은 포함되지 않습니다.

날씨는 [Open-Meteo](https://open-meteo.com/)에서 서울의 기온·습도·바람·예상 강수량을 가져옵니다. 인터넷 연결이 없거나 API 요청이 실패하면 일반 관리 팁을 보여줍니다. 야외 날씨는 참고용이며 실제 흙 상태와 실내 환경을 먼저 확인하세요.

## Android

현재 프로젝트는 웹 앱이며, APK 파일은 아직 생성되지 않았습니다. Android 앱으로 패키징하려면 별도의 Android 프로젝트와 빌드 도구가 필요합니다.
